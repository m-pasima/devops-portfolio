# 🌐 DevOps Portfolio – Beginner‑Friendly Setup Guide

Welcome! This little project turns a single **HTML file** into your personal DevOps portfolio website—no fancy tools required.  If you can click buttons and type in a browser, you can publish your site in **under 10 minutes**.

| You’ll Need | Why |

---

## 🚀 One‑Page Setup (≈ 5 minutes)

1. **Create your own copy**  
   • Click the **“Fork”** button at the top‑right of this page.  
   • Pick a name you like (or keep the default) and press **Create fork**.

2. **Personalise the web page**  
   • In *your* fork, open docs/index.html.  
   • Click the **✏️ Edit** icon.  
   • Replace the placeholders like Your Name, youremail@example.com, project links, etc.  
   • Scroll down and hit **Commit changes**.

3. **Publish with GitHub Pages**  
   • Still in your repo, click **Settings** → **Pages** in the left menu.  
   • Under **Branch**, choose main, and for **Folder** pick /docs.  
   • Press **Save**.  
   • Wait 30–90 seconds while GitHub builds the site.

4. **Visit your new portfolio**  
   • GitHub will show a green link like https://<your‑username>.github.io/<repo‑name>/.  
   • Click it—your site is live! 🎉

---

## 🔄 Updating Later

Any time you want to tweak text, colours, or add projects:
1. Open the file again (docs/index.html).
2. Click **✏️ Edit**, make changes, **Commit**.
3. Pages auto‑updates—refresh after a minute to see it.

## 🧰 Optional: Using the Desktop or Command Line

If you prefer local editing, you can **Clone** the repository with GitHub Desktop or git clone, edit in VS Code/Notepad, then push.  The web publishing step is the same.
